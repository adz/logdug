# Log Dug 0.5.2

Moves Log Dug onto .NET 11 and Axial 0.16. Nothing changes in how it looks or behaves.

## Changed

- Built with the .NET 11.0.100 SDK and targets `net11.0`.
- Uses Axial 0.16.0 and Reified 0.14.0.
- Startup waits for its runtime through Axial's own `Flow.run` instead of `Async.RunSynchronously`, so no file needs
  the `blocking` capability.
