# Log Dug 0.5.1

Log Dug moves to Axial 0.14.1. The search box hands its commands to an inbox owned by the runtime's layer instead of
offering to a bare queue, and the status line can now say when a burst of typing was coalesced.

## Search input

- `AppEnv.SearchCommands` is an `Inbox<SearchCommand>`, so `send` returns `Inbox.offer` instead of running a queue offer
  by hand in a command.
- The runtime builds the inbox with `Inbox.scopedSliding 1` inside its layer: it is shut down with the runtime's scope,
  and a newer command evicts the pending one, which is the newest-wins behaviour the pipeline already relied on.
- The search pipeline reads it with `Inbox.stream` and keeps the 200 ms debounce.
- The search status ends with `· N coalesced` once the mailbox has evicted a command, so a burst that was reduced to its
  newest query is visible instead of silent. `Inbox.dropped` counts an evicted sliding value from Axial 0.14.1; 0.14.0
  reported zero, which is why this release needs 0.14.1 rather than 0.14.0.
