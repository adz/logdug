# Log Dug 0.5.0

Log Dug moves to Axial 0.13.0. The app itself behaves as before; the changes are in how the search pipeline is owned,
where the clock is read, and how `--self-test` reports.

## Under the hood

- Axial 0.13.0 replaces 0.12.0 for every package and for the `axial` tool.
- The search pipeline is a runtime-owned service: `ElmishRuntime.startService` starts it inside the runtime's root scope,
  so stopping the runtime stops the pipeline and runs its finalisers, and a pipeline that ended early would be reported
  as a defect instead of being flattened by `Cmd.OfFlow.perform` with an unreachable `failwith`. The two start errors are
  startup programming errors with explicit messages, so the NativeAOT build keeps no `printf` or reflection formatting.
- The application's start time is read from the platform clock inside the runtime's layer, so the environment records one
  reading of the clock it actually runs with.
- `--self-test` reports through `DotNetApp.exitCode`: 0 when every check passes, 1 when a check fails, 2 when the checks
  themselves defect, and 130 when the run is interrupted.
