# Log Dug 0.2.0

## Highlights

- **An icon.** A smiling log with a shovel, in the executable, the window, the Start menu, the taskbar and the task switcher.
- **Right-click to open.** The Windows installer adds *Open with Log Dug* for files and folders and *Open Log Dug here* on a folder's background. On Linux, `scripts/install-linux.sh` installs the icon and a desktop entry so Log Dug appears in the launcher and *Open With*. Passing a file on the command line now opens its folder.
- **CSV and TSV tables.** Delimited files (comma, tab, semicolon or pipe) show as an aligned table with a highlighted header row. Quoted cells and newlines inside quotes are handled.
- **No more empty gap.** Logs without timestamps or levels no longer reserve blank columns on the left.
