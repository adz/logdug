# Log Dug 0.1.0

The first release.

## Highlights

- **Browse a folder of logs.** The tree shows the current directory, or a folder given on the command line. Zip, tar.gz and tgz archives open like folders, nested archives included, and `.gz` files open as text.
- **Read logs comfortably.** Levels are colour-coded and can be filtered. Strings, numbers, keys, exceptions, links and stack frames are coloured. Long lines wrap, and stack traces stay with their entry.
- **JSON lines.** Serilog compact (`@t`, `@mt`, `@l`, `@x`), pino and bunyan numeric levels, and common `timestamp`/`level`/`message` keys render as a message plus properties. The detail pane shows the pretty-printed JSON.
- **Search everything.** Plain text or regex, with optional match case, across every file including archive contents. Results stream in grouped by file, and Enter or F3 jumps to each match.
- **Times in any zone.** Show timestamps in UTC, the local zone, or a chosen zone. The active zone is always on screen.
- **Follow.** Reloads the open file as it grows, like `tail -f`.
- Light and dark themes.

## Under the hood

- All F#, with no C#. Avalonia 12.1 with ShadUI, Elmish through Elmish.Avalonia.Glue with F# viewmodels, Axial for effects and streams under Axial.Guardrails, and Reified for settings and query validation.
- NativeAOT builds for Windows, Linux and macOS. Each binary runs its own `--self-test` before it ships.
