# Log Dug 0.4.0

A maintenance release: the same app, now running on the released Axial 0.11.0, Reified 0.11.0 and Elmish.Avalonia.Glue 0.2.0 libraries.

## Fixed

- Updates from background work (search results, file changes) reach the UI in order. Elmish.Avalonia.Glue 0.2 serializes every dispatch on the UI thread; earlier versions could corrupt the update queue when background work dispatched at the same time.

## Under the hood

- Replaced the local dogfood prereleases (`0.11.0-local.*`, `0.12.0-local.*`, `0.2.0-local.*`) with the released nuget.org packages: **Axial 0.11.0**, **Reified 0.11.0** and **Elmish.Avalonia.Glue / Elmish.Glue.Core 0.2.0**, and removed the local NuGet feed.
- The Axial effects now run through `ElmishRuntime.startLayer`: the `Files` service, its archive cache, the search command queue and the event hub are provisioned in the runtime's scope, and the search pipeline runs as a long-lived service fiber.
- The hand-rolled `FileSystemWatcher` and `FlowCmd` bridge are gone; `Axial.Files.watch` feeds file changes, and `Cmd.OfFlow.*` / `Sub.OfFlowStream.*` drive commands and subscriptions.
- Shutdown uses `ElmishRuntime.StopAndWait`, and the host time zone is read once at the entry point and passed into the runtime.
- Reified `Data` and the settings codec come from the released **Reified 0.11.0** (dogfooded locally as `0.12.0-local.1`).
