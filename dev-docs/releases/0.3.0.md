# Log Dug 0.3.0

## Highlights

- **Find in the open file.** Each tab has its own find box (Ctrl+F) with its own text, a match count and next/previous, separate from the search over every file. Ctrl+Shift+F or `/` still search everything.
- **Fold JSON, XML and YAML.** Chevrons collapse indented blocks, with *Fold all* and *Unfold all*. Minified `.json` is spread over lines first, and `.gz` of any of these works.
- **Open a file by path.** A file given on the command line, or chosen from the Explorer *Open with Log Dug* menu, now opens itself instead of only its folder.
- **Right-click a file, folder or tab** for *Open in VS Code*, *Show in Explorer* (Finder, or the file manager on Linux), and *Copy path*.
- **CSV headers are detected, not assumed.** A first row of column names is shown as a header, and anything else is data. A *Header row* toggle overrides the guess for that file.
- **Close the results panel** with its ×.
- **Selected text is visible** when you drag over the log.
- Files with no levels (CSV, JSON, YAML) no longer show an empty "Other" filter chip.

## Also covered by tests

- `.gz` files inside a zip, and a `.tar.gz` (with a zip and logs inside it) inside a zip, open and read correctly.
